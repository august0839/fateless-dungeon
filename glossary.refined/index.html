    Fateless Dungeon — Glossary & Roadmap

    Glossary of Core Concepts

    Body (Core Stat)
    Represents physical condition. Substats: Strength, Fortitude, Dexterity.

    Mind (Core Stat)
    Represents thought and will. Substats: Intelligence, Memory, Willpower.

    Soul (Core Stat)
    Represents connection and essence. Substats: Empathy, Charisma, Faith.

    States
    Context-sensitive floats (0.0–1.0) that influence resilience and AI interpretation.
    - Combat → Body
    - Focus → Mind
    - Morale → Soul

    Resilience
    A hidden modifier for resistance. Not bounded to 0.0–1.0. Combined with States to determine defenses.

    Capacity
    How close an integrity pool (Body, Mind, Soul) is to collapse. Always between 0.0–1.0.

    Threshold
    A calculated total based on substats^5. Defines how much stress/damage a pool can handle before collapse.

    Integrity
    The “health” of a core stat, expressed as both Capacity and Threshold.

    Empowerment
    Mechanic where one substat boosts another (e.g., Faith empowering Strength). Comes at a cost, often self-damage to integrity.

    Float
    A decimal between 0.0–1.0. Replaces dice as the randomizing mechanism. Provides infinite nuance.

    Roadmap

    ✅ Phase 1: Foundations (Complete / Ongoing)

    • Define project philosophy (story-first, float-based system).
    • Manifest JSON for core alignment.
    • Basic stat framework (Body, Mind, Soul + substats).
    • Sandbox combat prototype (Farmer vs Goblin).

    🚧 Phase 2: Core System Build

    • Implement States (Combat, Focus, Morale) in Python.
    • Translate Google Sheet formulas into backend code.
    • Integrate Resilience, Capacity, Threshold into engine.
    • First character sheet JSON format.

    🔮 Phase 3: Narrative Integration

    • Prompt architecture for float → narrative conversion.
    • AI interprets checks with context, not mechanics.
    • Glossary references embedded in system prompts.

    🗺️ Phase 4: Campaign-Specific Builds

    • Ornia ruleset JSON (stats, states, empowerment logic).
    • Campaign content (characters, settings, conflicts).
    • Early playtesting with sample arcs.

    🌌 Phase 5: Expansion

    • Add glossary/guide to website (for newcomers).
    • Downloadables: sample JSONs, example character sheets.
    • Wider world-building (future campaigns beyond Ornia).
    • Community testing & contributions.
